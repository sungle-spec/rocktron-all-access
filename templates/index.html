Experimental hardware writes

Dump writes are disabled by default. The legacy transport attempts one-byte sends with a 15 ms delay. Actual wire timing and device receipt are unverified; enabling writes does not make restore reliable.

Host progress is available in the server terminal. A completed send still requires full device readback. See HARDWARE_TEST_PLAN.md before testing.

PC Map — incoming Program Change → preset (MIDI P6)

When the device receives PCn on its MIDI Receive Channel and Program Change Status = MAP, it recalls the mapped preset. Default mapping is identity (PC1→PR1, PC2→PR2, …).

Rocktron All Access — Web Editor & Virtual Foot Controller

Browser-based editor for the Rocktron All Access MIDI foot controller (1994). Partially reverse-engineered from tracked captures and session reports. Manufacturer ID 00 00 29, Device ID 08; bulk dump = 145 sysex frames totalling 43 647 bytes.

What you can edit

  • Preset name — 13 chars, A-Z 0-9 (the device's . renders as space).
  • 16 PC slots per preset — value (0-127) + active/OFF flag, one per MIDI channel.
  • Instant-access on/off bitmap — all 15 SWs (SW1-15), saved per preset via CTR STORE.
  • Custom MIDI commands — all 5 CMD slots per preset, full 18-type list.
  • SysEx string — 30 bytes per preset + ON/OFF toggle.
  • Songs — all 150 songs, 15 preset slots each (SW1-15).
  • Sets — all 10 sets, 50 banks → song mapping each.
  • PC Map — 128 incoming PC → preset slots.
  • Channel / switch / pedal names — 4-char custom names spliced into the name block.
  • Switch Type — LATCH / MOMENTARY / HOLD per switch.
  • Globals — Bank Size, MIDI Receive Channel, lower-range Remote Title, and Program Change Status. Starting Preset here is a UI preference.

What's read-only / partial

  • Per-preset PER-PR overrides — candidate decode; global interaction, sentinels, and some slot roles still need captures. No write UI.
  • Operating Mode — unresolved location; editing disabled.
  • Bank Style — real byte location unknown (the old guess was actually SW1's switch type); editing disabled.
  • MIDI filters — several type cells anchored; remaining types and channel regions still need verification. No edit UI.

Workflow

  1. Connect the MIDI interface using the manufacturer's cabling and power guidance.
  2. Pick your IN and OUT ports from the header dropdowns. LEDs go green when open.
  3. Read All (cloud-down icon) — arms the editor; trigger SYSX → DUMP → CTR STORE on the device.
  4. Edit any field in any tab. Each section's Save button splices your changes into the loaded dump bytes (non-destructive — every other byte preserved).
  5. Save .syx (floppy icon) — downloads the current in-memory dump to your ~/Downloads as a backup.
  6. Write All — experimental and disabled by default. Device receipt and reliable restore remain unverified. See HARDWARE_TEST_PLAN.md.
